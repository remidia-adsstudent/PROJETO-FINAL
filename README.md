# PROJETO INTEGRADOR

  Neste repositório estará armazenado todas as etapas do Projeto Final de Design Profissional da turma F.

  O objetivo deste projeto é investigar as exigências reais do mercado de trabalho em Tecnologia da Informação para orientar o desenvolvimento de competências profissionais do grupo e, a partir dessa base, projetar e validar o protótipo de uma solução tecnológica ética, inclusiva e segura voltada à mitigação da sub-representação e evasão de mulheres na área de TI.
